# Apple Health for AI Agents

Sync end-to-end encrypted Apple Health data from an iPhone or iPad to Codex,
Claude Code, OpenClaw, Hermes Agent, and other compatible agents.

[Website and installation guide](https://gethealthsync.app/) ·
[Plugin releases and offline downloads](https://github.com/lukasosterheider/apple-health-for-ai-agents/releases)

## Repository contents

- `skills/apple-health-sync/` contains the portable skill instructions, Python
  implementation, configuration reference, and tests. This is the editable source.
- `plugins/apple-health-sync/` contains the generated plugin package for Codex,
  including launchers and checksum-pinned runtime download manifests.
- `.agents/plugins/marketplace.json` is the Codex marketplace entry.
- GitHub Releases contain native runtimes for macOS, Linux, and Windows, plus
  complete offline ZIP and Claude Code TGZ packages.

The Git checkout contains no runtime binaries. The Codex launcher downloads only
the current platform's runtime on first use and verifies its SHA-256 checksum.
Claude Code gets its marketplace and package metadata from the website and its
package archive from GitHub Releases. Existing plugin and skill identifiers remain
`apple-health-sync`.

## Work on the portable skill

From this repository's root:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r skills/apple-health-sync/requirements.txt
.venv/bin/python -m unittest discover -s skills/apple-health-sync/scripts -p 'test_*.py' -v
```

On Windows, use `.venv\Scripts\python.exe` instead. See
[`SKILL.md`](skills/apple-health-sync/SKILL.md) for runtime usage and
[`references/config.md`](skills/apple-health-sync/references/config.md) for local storage.
The test workflow runs the Python tests when source changes are pushed or proposed.

Keep private keys, onboarding artifacts, local configuration, and health data out
of this repository. Runtime state belongs in the user's private state directory.

## Maintainer layout

The local workspace has two independent Git repositories:

```text
healthclaw/
├── Private/    iOS app, backend, website, plugin templates, and release tooling
└── Public/     this repository, including the portable skill source
```

Edit portable skills here. Plugin package files are generated by the separate
private release tooling, so changes to generated files must also be made in their
source templates. The release process only replaces the generated plugin folder
and marketplace entry; it preserves `skills/`, this README, and the public CI files.

The repository was renamed from `healthsync-codex-marketplace` to
`apple-health-for-ai-agents`. Existing release tags and assets are retained.
